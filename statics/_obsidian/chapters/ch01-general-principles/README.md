## 1.1 역학이란?

역학(Mechanics)은 물체에 작용하는 **힘**과 그 결과로 생기는 **운동** 또는 **평형 상태**를 연구하는 학문이다.

| 분야 | 내용 |
|------|------|
| 정역학 (Statics) | 정지 상태 또는 등속 운동 — 합력 = 0 |
| 동역학 (Dynamics) | 가속 운동 — 합력 ≠ 0 |

## 1.3 뉴턴의 세 가지 법칙

**제1법칙 (관성의 법칙)**  
합력이 0이면 물체는 정지 상태 또는 등속 직선 운동을 유지한다.
$$\sum \mathbf{F} = 0 \implies \mathbf{a} = 0$$

**제2법칙 (가속도의 법칙)**  
$$\mathbf{F} = m\mathbf{a}$$

**제3법칙 (작용-반작용의 법칙)**  
두 물체 사이의 힘은 크기가 같고 방향이 반대다.
$$\mathbf{F}_{AB} = -\mathbf{F}_{BA}$$

## 1.4 뉴턴의 중력 법칙
