## 5.1 강체 평형 조건

$$\sum \mathbf{F} = 0 \quad \text{(합력 = 0)}$$
$$\sum \mathbf{M}_O = 0 \quad \text{(임의 점에 대한 합 모멘트 = 0)}$$

2D에서:
$$\sum F_x = 0, \quad \sum F_y = 0, \quad \sum M_O = 0$$

---

## 5.2 지지 반력의 종류

| 지지 형태 | 기호 | 반력 수 | 반력 종류 |
|-----------|------|---------|-----------|
| 롤러 (Roller) | ○ | 1 | 수직 방향 N |
| 핀 (Pin) | △ | 2 | Ax, Ay |
| 고정단 (Fixed) | ▥ | 3 | Ax, Ay, MA |
| 로커 | ⌒ | 1 | 수직 방향 N |

---

## 5.3 2D 평형 풀이 절차

1. **FBD** 그리기 — 모든 반력 표시
2. **미지수** 파악 (최대 3개 풀이 가능)
3. 방정식 수립:
   - $\sum F_x = 0$
   - $\sum F_y = 0$
   - $\sum M_A = 0$ (A는 모멘트 팔이 최대인 점 선택)
4. 풀기

> **팁**: 모멘트 방정식의 기준점을 미지 반력이 여러 개 지나는 점으로 선택하면 계산이 단순해진다.

---

## 5.4 정정 / 부정정

| 조건 | 분류 |
|------|------|
| 미지수 = 방정식 수 | 정정 (Statically Determinate) |
| 미지수 > 방정식 수 | 부정정 (Statically Indeterminate) |
| 미지수 < 방정식 수 | 불안정 (Unstable) |

---

## 5.5 3D 평형

$$\sum F_x = 0, \quad \sum F_y = 0, \quad \sum F_z = 0$$
$$\sum M_x = 0, \quad \sum M_y = 0, \quad \sum M_z = 0$$

최대 **6개**의 미지수를 풀 수 있다.
