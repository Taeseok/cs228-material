## 6.1 트러스 (Truss)

- **단순 직선 부재**들이 **핀 절점**으로 연결된 구조
- 모든 하중은 절점에만 작용
- 각 부재는 **2-force member** → 축방향 힘만 전달

**부재 상태**:
- 인장 (Tension, T): 부재가 늘어나려는 힘 → 화살표 밖으로
- 압축 (Compression, C): 부재가 줄어들려는 힘 → 화살표 안으로

**정정 트러스 조건**:
$$m + r = 2j$$

| 기호 | 의미 |
|------|------|
| m | 부재 수 |
| r | 반력 수 |
| j | 절점 수 |

## 6.2 절점법 (Method of Joints)

각 절점을 **자유물체**로 분리하여 평형 방정식 적용:
$$\sum F_x = 0, \quad \sum F_y = 0$$

**풀이 순서**:
1. 외부 반력 계산 (전체 FBD)
2. 미지 부재력이 **2개 이하**인 절점부터 시작
3. 절점 순서대로 풀어 나가기

**제로-부재력 조건**:
- 2부재 절점에서 하중이 없고 두 부재가 일직선이 아니면 → 두 부재 모두 0
- 3부재 절점에서 두 부재가 일직선이고 하중 없으면 → 나머지 한 부재가 0

## 6.3 단면법 (Method of Sections)

특정 부재의 힘을 직접 계산할 때 유리:

1. 구하려는 부재를 **끊는 단면** 선택 (최대 3개 부재 절단)
2. 한쪽 자유물체 선택
3. 방정식: $\sum F_x = 0$, $\sum F_y = 0$, $\sum M = 0$

> 모멘트 기준점을 미지 부재력 2개의 교점으로 선택하면 계산이 간단해진다.

---

## 6.4 프레임과 기계

- **프레임**: 최소 하나의 **다중 힘 부재** (multi-force member) 포함, 정적 구조
- **기계**: 움직이는 부재 포함, 힘을 전달 또는 변환

**풀이 방법**:
1. 전체 구조 FBD → 외부 반력
2. 각 부재 분리 → 핀 연결부의 내력 분해 (Ax, Ay)
3. 각 부재별 평형 방정식
