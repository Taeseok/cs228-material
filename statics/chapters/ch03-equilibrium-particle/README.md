## 3.1 질점의 평형 조건

질점이 **정지** 상태이거나 **등속 운동** 중이면 평형 상태다.

$$\sum \mathbf{F} = 0$$

$$\sum F_x = 0, \quad \sum F_y = 0 \quad \text{(2D)}$$
$$\sum F_x = 0, \quad \sum F_y = 0, \quad \sum F_z = 0 \quad \text{(3D)}$$

---

## 3.2 자유물체도 (FBD)

> **정역학 풀이의 핵심 도구**

### 그리는 방법

1. 해석할 물체를 **주변 환경에서 분리** (isolate)
2. 작용하는 **모든 힘**을 표시:
   - 중력 (아래 방향)
   - 줄(케이블)의 장력 T (당기는 방향)
   - 스프링 힘 $F_s = ks$
   - 지지면의 수직 반력 N (면에 수직 방향)

### 주의사항
- 케이블은 **당기는 힘만** 전달 (T ≥ 0)
- 압축력은 전달 불가

---

## 3.3 2D 평형 방정식 풀이 절차

1. FBD 그리기
2. 미지수 확인 (케이블 장력, 반력 등)
3. 방정식 수립: $\sum F_x = 0$, $\sum F_y = 0$
4. 연립방정식 풀기

---

## 3.4 스프링

$$F_s = ks$$

| 기호 | 의미 |
|------|------|
| $k$ | 스프링 상수 [N/m] |
| $s$ | 변형량 (자연 길이에서의 늘어남/줄어듦) |

---

## 3.5 3D 평형

```
∑Fx = 0
∑Fy = 0  →  세 개의 미지수 최대 풀이 가능
∑Fz = 0
```
