Force Vectors

힘 벡터 — 합성, 분해, 내적

Engineering Mechanics: Statics — Hibbeler 14e

스칼라 vs 벡터

스칼라 (Scalar)

크기만 있는 물리량

  • 질량 (kg)
  • 온도 (°C)
  • 시간 (s)
  • 에너지 (J)

벡터 (Vector)

크기 + 방향이 있는 물리량

  • 힘 F (N)
  • 속도 v (m/s)
  • 변위 d (m)
  • 가속도 a (m/s²)

벡터 표기: F (볼드체) 또는 F⃗ (화살표)  |  크기: |F| = F

벡터 덧셈 — 평행사변형 법칙

F_R = √(F₁² + F₂² - 2F₁F₂cosθ)  (코사인 법칙)
F₁/sinθ₁ = F₂/sinθ₂ = F_R/sinθ  (사인 법칙)

2D 힘의 성분 분해

Fx = F cosθ
Fy = F sinθ
F = √(Fx² + Fy²)
θ = atan2(Fy, Fx)

💡 합력 계산 순서: 각 힘을 x, y 성분으로 분해 → ΣFx, ΣFy 계산 → 합력 크기·방향 계산

3D 힘 벡터 (직교 성분)

F = Fx î + Fy ĵ + Fz k̂
|F| = √(Fx² + Fy² + Fz²)

방향 코사인

각도정의관계
α (x축)cosα = Fx / Fcos²α + cos²β + cos²γ = 1
β (y축)cosβ = Fy / F
γ (z축)cosγ = Fz / F

단위 벡터: û = F / F = cosα î + cosβ ĵ + cosγ k̂

내적 (Dot Product)

A · B = AB cosθ = AxBx + AyBy + AzBz

두 벡터 사이 각도

θ = cos⁻¹( A·B / (AB) )

벡터의 축 투영

F_u = F · û

û 방향으로의 스칼라 성분

내적의 특성

  • 교환 법칙 성립: A·B = B·A
  • 수직인 두 벡터: A·B = 0
  • 단위 벡터: î·î = 1, î·ĵ = 0
